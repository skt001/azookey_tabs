# 英語 QWERTY ロングプレス候補 — 設計案

この資料は英語 QWERTY のロングプレス候補を検討するための設計案です。

候補は Unicode コードポイント、基本キーとの体系的関係、言語上の利用、句読法・記号としての用途などを基準に整理します。

### 大文字

大文字候補は小文字候補との Unicode 上の大文字小文字関係を基準に整理します。言語依存のマッピングも考慮します。

## 記号候補

設計対象には次のようなカテゴリを含めます。

- `¡` `¿`
- 引用符・アポストロフィ
- ハイフン・ダッシュ・マイナス
- 句読法
- 数学記号
- 通貨記号

例えば `+ = ±`、`* = ×` のような意味的に関連する候補も、設計上の候補として扱えます。

## 注意

この文書は**設計案**です。ここに掲載された候補のすべてが `examples/en_qwerty/` に実装されているとは限りません。
