# 日本語 QWERTY ロングプレス候補 — 設計案

この資料は日本語 QWERTY のロングプレス候補を検討するための設計案です。

## 英字

```text
a = a ａ
b = b ｂ
c = c ｃ
d = d ｄ
e = e ｅ
f = f ｆ
g = g ｇ
h = h ｈ
i = i ｉ
j = j ｊ
k = k ｋ
l = l ｌ
m = m ｍ
n = n ｎ
o = o ｏ
p = p ｐ
q = q ｑ
r = r ｒ
s = s ｓ
t = t ｔ
u = u ｕ
v = v ｖ
w = w ｗ
x = x ｘ
y = y ｙ
z = z ｚ
```

大文字についても同様に基本キーと全角形を候補として検討します。

## 特殊かな

小書きかな、歴史的かな、その他ローマ字入力から連想しやすい候補を検討します。

例:

```text
a = ぁ ァ
i = ぃ ィ
u = ぅ ゥ
e = ぇ ェ
o = ぉ ォ
t = っ ッ ゝ ゞ ヽ ヾ 〃 々
y = ゃ ゅ ょ ャ ュ ョ
w = ゎ ヮ ゐ ゑ ヰ ヱ
k = ゕ ヵ ゖ ヶ 箇
v = ゔ ヴ
```

## 数字

全角数字に加えて漢数字・大字を候補として検討します。

```text
1 = 1 １ 一 壱
2 = 2 ２ 二 弐
3 = 3 ３ 三 参
4 = 4 ４ 四 肆
5 = 5 ５ 五 伍
6 = 6 ６ 六 陸
7 = 7 ７ 七 漆
8 = 8 ８ 八 捌
9 = 9 ９ 九 玖
0 = 0 ０ 零 〇
```

## 記号・句読点

半角・全角対応に加え、キーの意味や用途から自然に連想できる関連記号を候補にできます。

例:

```text
. = . ． 。
, = , ， 、
- = - － − — – ー 〜
/ = / ／ ÷
% = % ％ ‰
+ = + ＋ ±
* = * ＊ ×
< = < ＜ ≤ ≦
> = > ＞ ≥ ≧
= = = ＝ ≡ ≈ ≠
```
